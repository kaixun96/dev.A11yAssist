# 统一 Accessibility Knowledge KB / MCP — PBI 与任务清单

更新：2026-09-15。范围：统一知识服务建设、消费者接入与旧知识插件替代。

## 目标与使用方式

**目标：所有需要无障碍知识的 plugin 通过宿主调用统一 Knowledge MCP；就绪并完成消费者迁移后，退役 `a11y-knowledge`、`a11y-knowledge-odsp` 及其他插件内嵌的重复知识模块。**

- KB 提供规则、适用性、来源、组件契约、案例和验证建议；不执行源码审查、页面操作、修复或任务编排。
- Bug Bash 等调用方负责确定范围、读取知识、审查源码、执行获授权的检查和生成报告。
- 对宿主保持一个 KB MCP 入口；MAS 连接由服务内部适配器管理。
- 本目录仅保存项目规划，不是新的知识包。正文在 [accessibility-kb](../accessibility-kb/README.md)，服务在 [knowledge-server](../knowledge-server/README.md)，本清单不进入知识快照。

每个 PBI 可作为独立 backlog 方向，下面的稳定 Task ID 可拆成工作项。
`[x]` 表示当前基线已交付，`[ ]` 表示待完成；Owner 为建议角色，实际人员待分配。
优先级：P0 = 首批交付必需，P1 = 消费者迁移必需，P2 = 持续改进。
有前置依赖的任务可先做设计，但不得在依赖未满足时宣称完成。

### 当前基线

- PR #31 的 `dd3946d` 已实现独立只读 MCP、精确版本/哈希快照、缓存与分发。
- 已迁入 AgentOW 固定版本中审查出的可复用无障碍规则；35 个条目：Common 20、Fluent 4、SharePoint 11，内容包版本 0.1.1。
- 已通过 KB 97 项、现有插件 79 项测试及两套生成检查；这些不是实时 MAS 或真实宿主验收结果。
- 现有插件尚未切换到该 MCP；MAS 接入尚未实现。
